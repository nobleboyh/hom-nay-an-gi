## Key differences from v1

| Aspect | v1 (AI-generated) | v2 (Figma spec) |
|--------|-------------------|-----------------|
| **Primary color** | `#D4562A` (chili-orange) | `#D97036` (warm orange) |
| **Secondary color** | None | `#8B6F47` (earthy brown) |
| **Typography** | Platform-native (system dynamic type) | Fixed sizes: 28/24/18/16/14/12px |
| **Border radius** | 8/16/24px + full | 12px buttons, 16px cards, full tags |
| **Card radius** | 16px | 16px (rounded-2xl) |
| **Home layout** | Ingredient input first | Surprise Me hero → nav cards → stats |
| **Ingredient input** | Simple input field | Input + ingredient list with +/- qty controls |
| **Recipe timeline** | Horizontal bar chart | Vertical numbered timeline |
| **Settings** | Grouped with toggles | Sections: Account, Notifications, Dietary, Appearance, Privacy, About |
| **Navigation** | 3 tabs + drawer for Settings | 3 tabs only (Home, Discover, Favorites) |
| **Bilingual** | Inline in UI | Vietnamese title + English subtitle on every screen |
| **Emoji style** | Emojis in UI | Emojis consistently used for dish images |
| **Button style** | Pill shape (rounded-full) | Rounded-xl (12px) |
