Hôm Nay Ăn Gì — UX Design Validation Report

DESIGN.md · EXPERIENCE.md · ux-hom-nay-an-gi-2026-06-01

Well-structured, internally consistent spine pair ready for architecture and story handoff with targeted remediation. The rubric walker rates the pair strong in 4 of 8 dimensions (flow coverage, visual reference coverage, bloat, shape fit) and adequate in 3 (token completeness, component coverage, inheritance discipline). Only state coverage rates thin — systemic loading/error/offline states are absent for every screen.

The accessibility and token-audit reviewers add 7 critical findings (9 critical total across all reviewers). The most impactful: 3 WCAG AA contrast failures (muted text at 3.8:1, border at 1.28:1, accent on white at 4.1:1), 5 undersized touch targets, and a spacing scale missing 7 commonly-used values (12px, 14px, 20px, 2px, 6px, 10px, 44px). These are token-level fixes, not architectural rework — darken 2–3 OKLCH values and add 3–4 spacing tokens. Patch the critical/high items before story-dev begins.

Accessibility review

review-accessibility.md

Does not meet WCAG 2.1 AA. The design system has systemic contrast failures (muted text at 3.8:1, borders at 1.28:1) and pervasive undersizing of tap targets. The Accessibility Floor section in EXPERIENCE.md shows awareness but lacks concrete implementation specifications. 7 critical, 4 high, 5 medium, 4 low findings.

critical

--muted text fails WCAG 1.4.3 contrast (3.8:1)

DESIGN.md Colors, Typography
--muted (oklch 50% 0.018 240) on --bg and --surface achieves ~3.8-4.07:1. Below 4.5:1 for normal text. Used for secondary text, timestamps, placeholders everywhere.
Fix: Darken to oklch(42% 0.022 240) for ~4.6:1, or prohibit for text <18px.
critical

--border fails WCAG 1.4.11 non-text contrast (1.4:1)

DESIGN.md Colors, Input Field, Card, Tab Bar
--border (oklch 90% 0.006 240) on white = ~1.4:1. Required 3:1 for non-text content. Affects input borders, card borders, dividers.
Fix: Darken to oklch(78% 0.012 240) or replace card borders with card-flat shadow.
critical

Multiple touch targets undersized (<44px)

DESIGN.md Tab Bar, Tag Chip, Button
Tab items ~38-42px, tag chips ~34px, standard button ~43.5px, ingredient chip remove glyph at 16px.
Fix: Add padding: 13px 14px to tags, 14px 24px to buttons, flex:1 to tab items. Remove target needs 44px pseudo-element.
critical

No keyboard model for click-delegated components

EXPERIENCE.md Interaction Primitives
Global click delegation for card expand, collapsible sections, checkbox/chip toggle. No role, tabindex, or keyboard event handling.
Fix: All clickable components must be <button> elements. If delegation, add role="button" + tabindex="0" + onkeydown for Enter/Space.
high

Toast-only form errors lack persistent announcement

EXPERIENCE.md State Patterns, Toast
Login errors, ingredient limits use 2-second toasts. No aria-live region, no aria-invalid on fields.
Fix: Add aria-live="polite" + role="status" to toast container. Apply aria-invalid to form fields. Increase dismiss to 4s.
high

lang="vi" specification too vague for bilingual app

EXPERIENCE.md Accessibility Floor
"Vietnamese content uses lang='vi'" without scope. Bilingual content needs language wrapping at phrase level.
Fix: lang="vi" on <html>. English phrases wrapped in <span lang="en">. Add language-switching utility spec.
high

Focus indicator insufficient: 1px color change only

DESIGN.md Input Field, EXPERIENCE.md Accessibility
1px border change from --border (1.4:1) to --accent (5.9:1). Minimal visual change — may not be visible to users with low vision.
Fix: outline: 2px solid --accent; outline-offset: 2px on all interactive elements.
high

No skip-navigation link

EXPERIENCE.md Layout, Navigation
Fixed top bar + bottom tab bar — keyboard users must tab through everything before reaching content.
Fix: Add visually-hidden skip link as first focusable element + landmark roles.
medium

Emoji-as-icons lack alt/aria spec

EXPERIENCE.md Voice and Tone
Screen readers announce Unicode descriptions (e.g., "camera with flash" for 📸).
Fix: Wrap in <span aria-hidden="true"> with visible text label.
medium

px-based font sizes may not respect system text size

DESIGN.md Typography
All sizes in px. Not responsive to iOS Dynamic Type or Windows Ease of Access.
Fix: Use rem or clamp() for font sizes: clamp(12px, 0.75rem, 16px) for meta.
medium

Toast feedback needs aria-live specification

EXPERIENCE.md Toast, State Patterns
All transient feedback uses toast but no aria-live region specified.
Fix: role="status" and aria-live="polite" on toast container. Minimum 4s dismiss.

Design token audit

review-token-audit.md

The token system is well-structured with semantic OKLCH tokens and a clean spacing/rounded scale, but has significant gaps. ~25% of component dimensions use hardcoded values not covered by the spacing scale; the border token fails WCAG non-text contrast; and several critical token categories (transitions, z-index, shadows, breakpoints, line-height) are entirely absent. 2 critical, 5 high, 14 medium, 5 low findings.

critical

--border on --surface fails WCAG 1.4.11 (1.28:1)

DESIGN.md Colors
--border (oklch 90% 0.006 240) on white = ~1.28:1. Required 3:1 for non-text contrast. Card borders, dividers, hairline rules nearly invisible.
Fix: Darken to oklch(80% 0.01 240) ≈ #C8C5C0 for ~3:1 against white.
high

Spacing scale omits 12px, 14px, 20px, 2px, 6px, 10px, 44px

DESIGN.md Spacing + Components
12px alone appears in button padding, toast padding, inter-item gap, ingredient-chip horizontal padding, timeline dot size. Current scale only has 4/8/16/24/32px.
Fix: Extend spacing scale or rationalise components to use existing tokens.
high

No shadow/elevation token scale

DESIGN.md Elevation & Depth
Three elevation levels with inline shadow values. No --shadow-sm/md/lg tokens.
Fix: Define shadow tokens matching the 3 elevation levels.
high

No line-height tokens defined

DESIGN.md Typography
Font sizes listed (10-28px) but no line-height values. Implementation will produce inconsistent vertical rhythm.
Fix: Add --leading-tight (1.2), --leading-normal (1.4), --leading-relaxed (1.6) or per-role line-heights.
medium

No transition/duration tokens

DESIGN.md Components
Three durations hardcoded: 0.15s, 0.2s, 0.3s.
Fix: Define --duration-fast (150ms), --duration-normal (200ms), --duration-slow (300ms).
medium

No z-index token scale

DESIGN.md Toast
Toast z-index 200 hardcoded with no token scale.
Fix: Define --z-toast (200), --z-tab-bar (100), --z-dropdown (50), --z-base (1).
medium

10 of 18 components use hardcoded spacing not in token scale

DESIGN.md Components
Tag Chip (14px), Ingredient Chip (6/12/14px), Input Field (14px), Button (12px), Tab Bar (20px), Toast (12px), Match Badge (2/10px), inter-item gap (12px), Timeline (44px).
Fix: Extend spacing scale or switch components to existing token values.
